# AGENTS.md — vyo-ceo

Este repositório documenta a camada estratégica e de negócio da VYO (marca, produto, preço, mercado, jurídico, metas). Ele **não contém código de produto** — isso vive em [`github.com/XandeJvSIlva/VYO`](https://github.com/XandeJvSIlva/VYO).

## Regras para qualquer IA ou colaborador editando este repositório

1. **Decisões críticas exigem aprovação de Nathan E Xande.** Preço e posicionamento nunca viram conteúdo "✅ Oficial" com base só em uma conversa ou proposta — precisam de validação explícita e registrada dos dois sócios. Na dúvida, mantenha como 🟡 Rascunho.
2. **Sempre marcar o status no topo do documento:**
   - ✅ **Oficial** — aprovado pelos dois sócios.
   - 🟡 **Rascunho** — pendente de validação.
   - 🔴 **Bloqueado** — depende de dado externo ou decisão que ainda não existe.
3. **Não invente dados reais.** Datas de fundação, valores de contrato fechado, nomes de clientes — se não estiver confirmado na fonte (Notion/Google Docs), marque como pendente (`[ ]` ou 🔴) em vez de preencher com um palpite.
4. **Notion é a fonte primária do dia a dia.** Este repositório é o snapshot versionado. Antes de declarar algo desatualizado ou de reescrever uma seção inteira, verifique a página correspondente no workspace **VYO • Central de tarefas**.
5. **Não duplique código ou specs técnicas de produto aqui.** Isso pertence ao repositório `XandeJvSIlva/VYO`. Este repositório referencia esse conteúdo quando relevante para uma decisão de negócio, mas não o reproduz.
6. **Preserve o vocabulário de marca já aprovado** (ver `docs/01-identidade-marca.md`) em qualquer texto novo escrito para uso externo: evite "disruptivo", "revolucionário", "sinergia", "plataforma robusta", "paradigma".
